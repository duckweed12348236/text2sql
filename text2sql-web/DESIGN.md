# Markable 平台设计基线

## 1. 视觉主题与氛围

面向公司内部算法、数据和运维人员的桌面工作台。整体采用 Notion 式的安静纸张层级、紧凑编辑器排版和低圆角矩形控件，标注工作台单独切换为深色画布，确保几何标注与原图保持高对比。

品牌关键词为精准、安静、可追溯。设计标志是贯穿全站的数据库属性色，钴蓝代表当前动作，薄荷绿代表完成，浅橙代表警告，浅蓝代表运行或排队。

## 3. 字体规则

字体采用 Monotype 的 Aptos Display 与 Windows 中文系统字体组合，避免额外网络字体依赖。页面标题使用 `Aptos Display, Microsoft YaHei`，正文与控件使用 `Aptos, Microsoft YaHei`。标题字重 600，字号 32/26/20px；正文 14px；辅助文字 12px；数字全部使用等宽数字。20px 以上标题使用轻微负字距。

## 4. 组件样式

- 主按钮为 8px 圆角的深墨色或钴蓝色矩形，悬停加深，按下缩放至 0.96。
- 输入框高度 40px，8px 圆角，默认细边界，聚焦显示 2px 钴蓝色焦点环。
- 状态属性使用 4px 或 6px 圆角的柔和色块，不使用胶囊作为普通按钮。
- 卡片只用于资源、状态和需要独立点击的对象，普通内容采用无卡片分区和细分隔线。
- 抽屉用于队列、通知和上下文详情，创建与发布等需要聚焦的操作使用对话框。

## 5. 布局原则

桌面端采用 238px 左侧栏、56px 顶栏和弹性主工作区。内容区最大宽度 1480px，横向间距 24px，纵向节奏 12/16/24/32px。工作台先展示状态摘要，再展示任务与资源细节。标注页使用缩略图导航、中心画布、对象属性三栏布局。

## 6. 深度与层级

层级主要通过背景色台阶和 1px 分隔线表达。普通区域不使用装饰性阴影，抽屉、命令面板和浮动工具栏使用 `0 12px 36px rgba(15,15,15,0.14)`。相邻表面至少在 `#ffffff`、`#fafaf9`、`#f6f5f4` 三档之间切换。

## 7. 约束

- 不使用紫蓝渐变、玻璃拟态、装饰性大阴影或营销页 Hero。
- 不把所有内容装进相同卡片。
- 未标注与负样本始终使用不同状态。
- 删除、归档和强制释放锁保留确认与恢复说明。
- 关键点和旋转框不展示虚假的训练入口。
- GPU 队列严格表达串行，不提供优先级或插队入口。
- 所有界面图标使用 Element Plus 的内联 SVG，不使用 emoji。标注与测试示例使用项目内 GPT Image 生成的工业样本图。
- 页面进入采用 220～260ms 的淡入上移，进度条按数据方向展开，运行状态使用低频脉冲和旋转；仅动画化 `transform` 与 `opacity`，并支持 `prefers-reduced-motion`。

## 8. 响应式行为

产品主要面向桌面 Chrome 与 Edge。宽度低于 900px 时侧栏收起为抽屉，表格允许横向滚动，常规浏览页保持可用。标注工作台在窄屏显示明确的桌面端使用提示，不伪装成可完成移动标注。

## 9. 后续组件提示

- 创建状态摘要条：白色画布，五列数字，数字 28px/600，标签 12px，列间使用 `#e5e3df` 分隔线。
- 创建数据集表格：表头 `#fafaf9`，行高 58px，任务类型使用 6px 圆角属性色，行悬停 `#f6f5f4`。
- 创建标注工具按钮：40px 方形，8px 圆角，默认透明，选中 `#e7edff`，图标 `#2458d3`，按下缩放 0.96。
- 创建 GPU 队列抽屉：宽 420px，运行任务使用 `#dcecfa`，等待任务使用 `#f6f5f4`，数字使用等宽数字。
